# Telegram P2P Guarantee Bot

Этот репозиторий содержит реализацию Telegram-бота "P2P Guarantee / OTC" в соответствии с техническим заданием.

## Возможности

- Главное меню со стартовой карточкой и разделами управления.
- Управление реквизитами TON и RUB, проверка и пополнение баланса.
- Создание сделок с выбором валюты, суммой и описанием.
- Генерация уникальной ссылки для покупателя и управление статусами сделки.
- Интерфейс покупателя с кнопками оплаты и отмены.
- Реферальная система с уникальными ссылками и статистикой.
- Переключение языка интерфейса (русский / английский).

## Быстрый старт

1. Создайте и активируйте виртуальное окружение.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` (по желанию) или экспортируйте переменные окружения:
   - `BOT_TOKEN` — токен Telegram-бота.
   - `BOT_USERNAME` — username бота без `@` (нужен для генерации ссылок).
   - `DATABASE_PATH` — путь к файлу SQLite (по умолчанию `data/bot.db`).
4. Запустите бота:
   ```bash
   python main.py
   ```

## Структура данных

- `users` — хранит пользователей, их реквизиты, балансы и реферальные связи.
- `deals` — хранит сделки, их статус и уникальные токены для ссылок.
